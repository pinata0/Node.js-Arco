# Project Arco

Project Arco is a web-service MVP that recommends events users can attend on a chosen date, based on their interests. Supported event types will include:

- Seminars
- Conferences
- Meetups
- Hackathons

## Initial structure

```text
frontend/  - Frontend application
backend/   - Backend API server
docs/      - Project documentation
prompts/   - Development prompts
```

This repository is currently at the initial scaffold stage. The frontend and backend applications have not been initialized yet.
